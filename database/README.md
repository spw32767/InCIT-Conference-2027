# Database — MariaDB

โฟลเดอร์นี้เตรียมไว้สำหรับ schema, migrations และ seed data ในขั้นตอนถัดไป
ใช้เก็บไฟล์โครงสร้างและประวัติการเปลี่ยนแปลงใน Git ไม่ใช่ที่เก็บข้อมูลจริงหรือตัว MariaDB Server
ยังไม่มีการสร้างฐานข้อมูล ตาราง หรือข้อมูลตัวอย่าง

ติดตั้ง npm package `mariadb` ใน backend แล้ว แต่ยังไม่ได้เชื่อมต่อฐานข้อมูล
ทีมใช้ MariaDB Server สำหรับพัฒนาที่เตรียมไว้แล้วร่วมกัน โดยแยกจาก production
สมาชิกไม่ต้องติดตั้งหรือรัน MariaDB บนเครื่องตนเอง และจะใช้ฐานข้อมูลก้อนเดียวกันผ่าน backend
ไฟล์ migrations และ seed ที่เพิ่มภายหลังจะใช้กับ Server กลางนี้ได้
ควรประสานงานกับทีมก่อนรันคำสั่งที่เปลี่ยน schema หรือข้อมูลร่วมกัน

ตัวแปรสำหรับการเชื่อมต่อเตรียมไว้ใน `backend/.env.example`
คัดลอกเป็น `backend/.env` แล้วกรอกข้อมูล Server สำหรับพัฒนาที่ได้รับจากทีม
ขณะนี้ยังไม่มีโค้ดอ่านตัวแปร DB หรือการเชื่อมต่อ Server จริง
ห้ามบันทึกรหัสผ่านจริงลงใน Git
